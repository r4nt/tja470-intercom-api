Allow establishing a SIP connection with the provided information from 
the main API.
That SIP connection should be able to receive incoming SIP calls as well as make calls to other SIP numbers or cameras.
It should allow receiving and transmitting audio, with audio being sent in a raw format or converted to a format usable from a websocket in a browser.
The setup should in the end be usable from a home assistant integration, which will contain a lovelace card that shows the active call and allows user control over the call (answer, reject, hangup, open door at position, switch camera).
